# Proposed architectural sketch reconstruction rule

"
            "**Status: proposal — not yet canonical USG v0.12 protocol.**

"
            "Architectural sketches communicate through explicit dimensions, topology, proportion and perspective. A reconstruction system should not treat every undimensioned feature as unusable.

"
            "## Proposed rule

"
            "**Dimensions override proportion. Proportion fills the gaps. User clarification resolves contradictions.**

"
            "Suggested evidence states:

"
            "- `exact` — explicitly dimensioned or stated; build exactly.
"
            "- `derived` — calculated from exact information without adding unsupported intent.
"
            "- `approximate` — intent is clear but value/geometry is inferred proportionally; reconstruct and label approximate.
"
            "- `observed` — presence/relationship is visible but usable geometry is not reliable.
"
            "- `ambiguous` — multiple materially different readings remain; ask the user.
"
            "- `unknown` — no useful information exists; leave unresolved.

"
            "Do not confuse uncertainty of measurement with uncertainty of design intent. Ask the user when explicit evidence conflicts or ambiguity materially changes the design, not for every missing dimension.
