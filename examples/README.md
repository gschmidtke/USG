# USG examples

Worked examples belong here.

Each example should ideally include:

- source evidence or a description of it;
- the stage where USG entered;
- which stages were resolved;
- explicit assumptions and ambiguities;
- acceptance invariants;
- the software-neutral handoff payload;
- any downstream feedback that later contradicted a USG premise.

The first planned example is **Building 001**, using the hand sketch experiment that established the rule:

> Dimensions override proportion. Proportion fills the gaps. User clarification resolves contradictions.

Building 001 should remain a concept-resolution example, not a Revit-specific implementation example.
